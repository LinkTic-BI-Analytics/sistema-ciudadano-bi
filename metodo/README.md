## La idea en un párrafo

La mitad de las preguntas de un requerimiento **no se pueden hacer en una reunión**, porque
nadie sabe que son preguntas hasta que hay que decidirlas para poder construir. Entonces no
se escribe el requerimiento completo y después se construye: se escribe rápido y flojo, se
construye un pedazo, y **lo que construir obligó a decidir vuelve al documento**. El
requerimiento formal se escribe de último, cuando ya se sabe.
